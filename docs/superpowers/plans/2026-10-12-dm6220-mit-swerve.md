# DM6220 MIT 直驱舵轮 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将舵向电机改为 DM6220 MIT 直驱，实现遥控每次重新使能后的安全回零、ID1 单轮组控制以及 USART9 VOFA 24 通道与 RAM 在线调参。

**Architecture:** 复用通用 DM 驱动并增加可观察的反馈更新计数；舵轮模块保持纯运动学并增加轮组状态重置；底盘任务维护活动轮组和回零状态机；调试任务负责固定周期快照及参数命令暂存，10 ms 前台任务负责实际应用。首轮仅激活 LF 的 DM ID1 与 VESC ID1，ID2～4 只初始化和封装。

**Tech Stack:** C++17、STM32H723 HAL、FDCAN1/FDCAN3、USART9 JustFloat、裸机 10 ms/20 ms 调度、MinGW g++ Native 主机测试、CMake/Ninja ARM 固件构建。

**Spec:** `docs/superpowers/specs/2026-10-12-dm6220-mit-swerve-design.md`

## Global Constraints

- 只修改 `Robocon-Elian`，不得修改 VESC `bldc` 参考源码、CubeMX 生成目录或无关模块。
- 不引入 RTOS、队列、SUBS、动态内存、异常、RTTI 或新的管理层。
- DM6220 使用 FDCAN1、MIT 模式、ID1～4；VESC 使用 FDCAN3、ID1～4。
- 上电默认失能；遥控离线或失能时 U8 清零、活动 DM 退出使能并复位回零状态。
- 每次遥控失能到使能都重新回零；回零前和回零超时后活动 U8 目标均为 `0 ERPM`。
- 不发送保存零点命令，不修改 DM Flash；上位机保存的 ID1 `0 rad` 对应舵轮机械正前方。
- MIT 默认值固定为 `Kp=7.0`、`Kd=0.20`、`v_des=0 rad/s`、`tau_ff=0 N·m`。
- 回零完成条件为 `abs(position)<=0.05 rad` 且 `abs(velocity)<=0.5 rad/s` 连续 100 ms；超时为 3 s。
- DM MIT 协议量程为 `±251.3 rad`、`±45 rad/s`、`±10 N·m`；舵向软件边界使用 `±245 rad`。
- 正常控制后 DM 在线状态只用于诊断，不新增 DM 掉线联动 U8 清零逻辑。
- USART9 在线调参只写 RAM；允许范围为 `Kp 0～50`、`Kd 0～5`、`tau_ff -2～2 N·m`，越界直接拒绝。
- 对外常量、枚举、结构体和函数声明放在 `.h`；文件私有状态与 `static` 辅助函数留在 `.cpp`。
- 使用 Native 原地执行，不创建分支、不提交 Git、不覆盖用户无关改动。
- 每个独立模块只运行相关测试；全部完成后统一运行全部主机测试，最后只进行一次 Debug 固件完整编译。

## Review Focus

- 重新使能时旧反馈不能让状态机跳过 `WAIT_FEEDBACK`；Task 1 和 Task 3 用反馈更新计数覆盖。
- 回零条件短暂满足后再次越界必须清零连续稳定计数，不能提前进入 `READY`；Task 3 覆盖。
- ID2～4 未激活时不得发送 Enter 或控制帧，也不能阻塞 ID1 回零；Task 3 覆盖。
- VESC/DM 反馈超时后 VOFA 连续量必须为 `NaN`，不能继续输出旧值；Task 4 覆盖。
- USART9 越界、未知或重复读取的命令不得改变 MIT 参数；每条有效命令只能消费一次；Task 4 覆盖。
