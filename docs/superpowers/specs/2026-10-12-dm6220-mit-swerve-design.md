# DM6220 MIT 直驱舵轮与 USART9 VOFA 调试设计

## 1. 目标与约束

本次修改将四舵轮底盘的舵向电机由带 `17:215` 外啮合齿轮的 DM3519 改为 DM6220 直驱，并将舵向控制模式改为 MIT。首轮实体测试只使用左前轮组 `DM6220 ID 1 + VESC ID 1`，ID 2～4 完成相同封装但保持未激活。

成功标准：

- 遥控每次从失能切换到使能时，活动 DM6220 自动回到上位机已经保存的 `0 rad` 零点。
- 回零完成前，对应 U8 的目标始终为 `0 ERPM`。
- 正常控制使用直驱舵向角、连续角度和最近等效目标，不再保留 DM3519 齿轮换算。
- USART9 VOFA 输出 VESC 与 DM6220 的 24 路固定诊断量，并允许有限范围内在线调整 MIT 参数。
- 保留裸机周期调度、遥控使能控制和现有 CAN 总线分工，不引入 RTOS、队列、SUBS 或额外管理层。

不在本次范围内：

- 不向 DM6220 发送保存零点命令，不修改电机 Flash 中的上位机零点。
- 不修改 VESC FOC、速度 PID、电流限制或制动配置。
- 不启用 DM ID 2～4 与 VESC ID 2～4 的实际底盘控制。
- 不对全部 `User_File` 做无关重构。

## 2. 硬件与节点映射

| 轮组 | DM6220 | VESC | 当前状态 |
| --- | --- | --- | --- |
| LF | FDCAN1，ID 1，反馈 ID `0x11` | FDCAN3，ID 1 | 激活 |
| RF | FDCAN1，ID 2，反馈 ID `0x22` | FDCAN3，ID 2 | 已封装、未激活 |
| LB | FDCAN1，ID 3，反馈 ID `0x33` | FDCAN3，ID 3 | 已封装、未激活 |
| RB | FDCAN1，ID 4，反馈 ID `0x44` | FDCAN3，ID 4 | 已封装、未激活 |

活动轮组由集中定义的位掩码选择，首轮仅设置 `Swerve_Wheel_LF`。未激活轮组不使能、不等待反馈，也不参与回零完成判定。

## 3. 模块边界

### 3.1 `dvc_motor_dm`

继续复用 `Class_Motor_DM_Normal`，不新增重复的 `Class_Motor_DM6220`。驱动层只负责：

- DM MIT 报文编解码；
- 使能、失能和错误清除报文；
- 单圈与连续角度、速度、转矩、温度和在线状态；
- 按电机初始化参数约束 MIT 输出。

DM6220 MIT 量程：

```text
position: -251.3 ～ 251.3 rad
velocity:  -45.0 ～ 45.0 rad/s
torque:    -10.0 ～ 10.0 N·m
Kp:          0.0 ～ 500.0
Kd:          0.0 ～ 5.0
```

驱动层不负责舵轮回零状态机、遥控状态或 U8 联锁。

### 3.2 `motor_init`

DM ID 1～4 均使用 `Motor_DM_Control_Method_NORMAL_MIT` 初始化，上电默认失能。初始 MIT 参数集中定义：

```text
p_des  = 0 rad
v_des  = 0 rad/s
Kp     = 7.0
Kd     = 0.20
tau_ff = 0 N·m
```

`v_des` 在 MIT 模式中是目标速度，不再沿用 DM3519 位置速度模式中的“速度上限”含义。

### 3.3 `mod_chassis_swerve`

保留现有模块的底盘运动学、摇杆离开零区的启停迟滞、90°附近的正反转迟滞以及最近等效角选择。增加一个显式的轮组目标重置接口，使每次回零成功后能够用当前零位重新初始化该轮组的连续目标与上一次目标，避免重新使能后跳回旧目标。

模块仍只处理机械舵向角和行进轮角速度，不直接访问 DM 或 VESC 对象。

### 3.4 `tsk_chassis`

任务层负责：

- 活动轮组选择；
- 遥控使能边沿检测；
- DM6220 回零状态机；
- DM 电机角与舵轮机构角之间的直驱换算；
- 正常舵轮解算结果下发；
- 舵向误差限速、U8 速度斜坡和回零阶段 U8 清零；
- 回零诊断数据维护。

### 3.5 `tsk_debug`

USART9 VOFA 的数据快照、JustFloat 发送、命令解析结果消费和 MIT RAM 调参全部放在 `tsk_debug`。USART9 中断回调只解析并暂存命令；实际参数在 10 ms 前台周期应用，不在中断上下文直接修改电机控制量。

## 4. 遥控使能与回零状态机

每个轮组保存独立状态，状态枚举固定为：

```text
0 DISABLED         失能
1 WAIT_FEEDBACK    等待首帧有效反馈
2 HOMING           正在回零
3 READY            回零完成，正常控制
4 TIMEOUT          回零超时
```

首轮只有 LF 状态机参与运行。

### 4.1 状态转换

遥控离线或失能：

- 活动 VESC 目标清零并失能；
- 活动 DM 发送退出使能；
- 回零状态复位为 `DISABLED`；
- 稳定计数、超时计时和行进轮斜坡状态清零。

遥控由失能切换为使能：

1. 活动 DM 进入使能，状态切换到 `WAIT_FEEDBACK`。
2. 活动 VESC 可以保持协议通信，但控制目标固定为 `0 ERPM`。
3. 当 `Get_Total_Angle_Initialized()` 为真且存在有效 DM 反馈后，进入 `HOMING`。
4. `HOMING` 中持续发送：

   ```text
   p_des=0 rad, v_des=0 rad/s, Kp=7.0, Kd=0.20, tau_ff=0 N·m
   ```

5. 同时满足以下条件并连续保持 100 ms（10 个 10 ms 周期）后进入 `READY`：

   ```text
   abs(position feedback) <= 0.05 rad
   abs(velocity feedback) <= 0.5 rad/s
   ```

6. 进入 `READY` 时，以当前零位重置舵轮解算器的连续目标，然后开始响应底盘运动指令。

从遥控使能边沿起计时，3 秒内未进入 `READY` 则切换到 `TIMEOUT`。超时后 DM 保持使能并继续保持 `0 rad`，U8 保持 `0 ERPM`；只有遥控先失能再重新使能才清除超时并重试。

### 4.2 正常运行中的在线状态

按照已经确认的现阶段策略，DM 软件在线状态在 `READY` 后只用于诊断，不新增“DM 掉线立即联动强制 U8 为 0”的逻辑。该决定不改变遥控离线/失能时的整车清零和失能保护。

## 5. DM6220 直驱舵向解算

### 5.1 直驱换算

删除原 DM3519 的 `17:215` 齿轮比和外啮合反向换算。每轮只保留安装方向与软件偏移：

```text
mechanism_angle = motor_angle * direction - offset
motor_target    = (mechanism_target + offset) * direction
mechanism_omega = motor_omega * direction
```

LF 上位机保存的 `0 rad` 对应舵轮机械正前方，因此首轮 `offset=0 rad`。方向初值沿用 `+1`，若实体方向相反，只调整对应轮组方向常量。

### 5.2 最近等效目标

每个轮组先根据底盘速度得到：

```text
wheel_speed = hypot(wheel_speed_x, wheel_speed_y)
base_angle  = atan2(wheel_speed_x, wheel_speed_y)
```

处理规则：

1. 轮速低于现有退出阈值时保持上一次有效舵向，避免 `atan2(0, 0)` 和摇杆死区噪声造成跳变。
2. 分别计算 `base_angle` 与 `base_angle + π` 相对当前连续角度的最近等效目标。
3. 选择舵向行程更小的方案；选择反向方案时，行进轮速度取反。
4. 保留现有 10° 正反转迟滞，避免接近 90°时反复翻转。
5. 正常情况下单次目标变化不超过约 90°。

DM6220 MIT 位置协议不是数学意义上的无限范围。软件目标使用约 `±245 rad` 的软边界，为协议的 `±251.3 rad` 留出余量。舵轮机构允许连续旋转，但算法不主动累计无意义圈数；接近边界时只选择范围内的等效目标，不发送保存零点命令，也不发生数值回绕。

### 5.3 MIT 正常控制量

```text
p_des  = 最近等效的连续舵向目标 rad
v_des  = 0 rad/s
Kp     = 当前 RAM 调参值
Kd     = 当前 RAM 调参值
tau_ff = 当前 RAM 调参值，仅 READY 状态生效
```

舵向速度由位置误差、`Kp/Kd` 和 DM6220 内部限制共同形成，不用 `v_des` 充当速度上限。

## 6. U8 联动与现有速度限制

回零状态不是 `READY` 时，活动 VESC 的控制目标固定为 0，且行进轮斜坡状态复位，防止回零完成后从旧速度继续输出。

进入 `READY` 后保留现有功能：

- 舵向误差小于约 5°时允许全速；
- 舵向误差在约 5°～45°之间线性限速；
- 舵向误差达到约 45°时目标速度为 0；
- STM32 行进轮加减速斜坡继续生效；
- VESC 内部 Ramp 继续作为单电机保护层。

舵向误差必须基于直驱机构角度计算，不能再使用齿轮换算后的旧量。

## 7. USART9 VOFA

### 7.1 发送节拍

`Debug_20ms_PeriodElapsedCallback()` 每 20 ms 形成并发送一次当前快照，不再以 VESC `STATUS_5` 新帧作为发送触发条件。各通道按其 CAN 帧实际频率更新，20 ms 输出采用最近一次仍有效的数据。反馈超时后不得继续把旧值当作实时值；失效的连续量通道写入 IEEE-754 `NaN`，状态通道按各自定义写入离线或失能值。

发送继续使用现有非阻塞 UART DMA 链路，高频任务中不增加 `printf` 文本输出。

### 7.2 通道定义

| 通道 | 含义 | 单位 |
| --- | --- | --- |
| I0 | VESC 目标机械转速 | rpm |
| I1 | VESC 实际机械转速 | rpm |
| I2 | VESC 速度误差 | rpm |
| I3 | VESC 电机电流 | A |
| I4 | VESC 占空比 | % |
| I5 | VESC 输入电流 | A |
| I6 | VESC 母线电压 | V |
| I7 | VESC MOS 温度 | ℃ |
| I8 | DM6220 目标位置 | rad |
| I9 | DM6220 实际位置 | rad |
| I10 | DM6220 位置误差 | rad |
| I11 | DM6220 目标速度 | rad/s |
| I12 | DM6220 实际速度 | rad/s |
| I13 | DM6220 前馈转矩 | N·m |
| I14 | DM6220 反馈转矩 | N·m |
| I15 | DM6220 Kp | 无量纲 |
| I16 | DM6220 Kd | 无量纲 |
| I17 | DM6220 MOS 温度 | ℃ |
| I18 | DM6220 电机温度 | ℃ |
| I19 | DM6220 反馈状态码 | 数值 |
| I20 | DM6220 软件在线状态 | 0/1 |
| I21 | DM6220 目标使能状态 | 0/1 |
| I22 | DM6220 回零状态 | 0～4 |
| I23 | DM6220 回零耗时 | ms |

默认观察 LF，即 DM ID 1 与 VESC ID 1。已有轮组选择接口保留，后续激活 ID 2～4 时可直接切换观察对象。

### 7.3 RAM 在线调参

支持以下命令：

```text
dm_kp=7.0#
dm_kd=0.20#
dm_tau_ff=0.0#
```

初始允许范围：

```text
Kp:      0 ～ 50
Kd:      0 ～ 5
tau_ff: -2 ～ 2 N·m
```

越界值拒绝，不静默截断。命令值只保存在 RAM，重新上电恢复默认值。回零期间强制 `tau_ff=0`，用户设定的前馈转矩只在 `READY` 状态生效。

## 9. 测试与验证

优先复用现有 Native 主机测试环境，测试顺序为：

1. DM 驱动相关测试：MIT 量程、打包、限幅、反馈连续角度。
2. 电机初始化测试：ID 1～4、FDCAN1、MIT 模式、默认参数和默认失能。
3. 舵轮模块测试：死区保持、最近等效目标、驱动反向、迟滞、重置与软边界。
4. 底盘任务测试：
   - 失能到使能进入回零；
   - 首帧反馈等待；
   - 连续 100 ms 判定；
   - 3 秒超时；
   - 失能后重新使能重试；
   - 回零前 U8 为 0；
   - 只有 LF 活动，ID 2～4 不阻塞。
5. 调试任务测试：24 通道顺序、单位、20 ms 输出、三项调参、越界拒绝和 RAM 应用。
6. 每个模块完成后仅运行其相关测试；全部修改结束后统一运行一次全部主机测试。
7. 最后执行一次 `build/Debug` 固件完整编译与链接，目标为 `Robocon-Elian.elf`。

软件测试和固件编译通过只证明代码路径与构建正确。DM6220 实际回零方向、MIT 增益、机械抖动和 U8 联动仍需烧录后在实体硬件上验证。

## 10. 实机首轮验证顺序

1. 架空 ID1 轮组，仅接 DM6220，遥控失能上电，确认电机不动作。
2. 遥控使能，观察 I8～I23，确认状态依次经过 `WAIT_FEEDBACK → HOMING → READY`。
3. 确认回零方向正确；若方向相反，只调整 LF 安装方向常量，不修改上位机零点。
4. 轻微改变舵向命令，确认目标位置连续且 `v_des` 保持 0。
5. 再连接 VESC/U8，确认回零完成前 I0 恒为 0，完成后才响应遥控。
6. 从保守 `Kp=7.0、Kd=0.20、tau_ff=0` 开始，根据 I8～I16 波形逐步调参。
